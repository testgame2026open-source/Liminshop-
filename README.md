# Liminshop - Маркетплейс

Маркетплейс для продажу і покупки товарів з системою чата між продавцем і покупцем.

## Установка

### 1. Клонування репозиторію
```bash
git clone https://github.com/testgame2026open-source/Liminshop-.git
cd Liminshop-
```

### 2. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 3. Запуск додатку
```bash
python app.py
```

Сайт буде доступний за адресою: `http://localhost:5000`

## Функції

✅ **Каталог товарів** з фільтрами:
- По назві
- По ціні (від-до)
- По категоріям (Сад, Машини, Бізнес/Дом, Інструменти, Техніка, Ігрушки)

✅ **Система чата** у реал-тайм:
- Прямий чат між покупцем і продавцем
- Збереження всіх повідомлень
- Можливість перемістити чат в корзину (soft delete)

✅ **База даних** (SQLite):
- Користувачі
- Товари
- Чати
- Повідомлення

## API Endpoints

- `GET /api/products` - Отримати товари з фільтрами
- `POST /api/chat/start` - Почати чат
- `GET /api/chat/<id>/messages` - Отримати повідомлення
- `POST /api/chat/<id>/message` - Відправити повідомлення
- `POST /api/chat/<id>/delete` - Видалити чат (soft delete)
